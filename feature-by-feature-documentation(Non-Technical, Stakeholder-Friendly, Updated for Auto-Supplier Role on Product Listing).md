# Feature Overview

## OpenRouter Integration
- Users supply an API key for OpenRouter.
- The app connects to the `moonshotai/kimi-k2:free` model.

## Capture and Assistance
- Continuous screen and audio capture provide context to the AI.
- Responses appear in real time within the transparent overlay.

## History and Profiles
- Previous sessions are stored locally for review.
- Multiple conversation profiles tailor responses for interviews, meetings, or negotiations.
